# Marea

A cinematic, responsive travel website for soulful stays and unhurried journeys across Algeria.

## Run locally

```bash
npm start
```

Then visit [http://localhost:4173](http://localhost:4173).

## Highlights

- Editorial, mobile-first visual system
- Curated stay filtering and save interactions
- Working trip-planning and stay-enquiry dialogs
- Newsletter signup feedback
- Scroll reveals with reduced-motion support
- Keyboard-friendly navigation and semantic HTML
- Zero runtime dependencies

All imagery in `assets/` was created specifically for this project.
